Iot Sensor Data Analysis

📌 Project Overview 

The project analyzes one month data collected from temperature and humidity sensors installed at five different locations (Plant A, Plant B, Warehouse North, Warehouse South and Lab). The main goal of this project is to monitoring the environment of different locations and the condition of sensors to control the environment of locations and avoid any device failures.

🎯 Project Objectives

- Clean and process the readings of temperature and humidity sensor to find insights.
- Analyze the environment conditions of five different locations.
- Analyze the health of devices.

🛠️ Tools & Technologies

Python - Data cleaning, preprocessing, and transformation. 
Pandas - Data manipulation and analysis. 
NumPy - Numerical operations and data processing.
MySQL - Data querying and exploratory analysis.
Power BI - Interactive dashboard creation and data visualization.

🔄 Project Workflow

Data Cleaning & Transformation — Used Python to prepare the raw dataset for analysis.
Key activities included:

Handling missing and null values. Identifying and removing duplicate records. Correcting data types and formatting inconsistencies. Standardizing column names and categorical values. Transforming data into a clean and analysis-ready format. Preparing the processed dataset for database analysis and visualization.

Libraries used: Pandas, NumPy.

Data Analysis — MySQL- Imported the cleaned dataset into MySQL and performed SQL-based analysis to uncover meaningful insights into customer behavior.
Key activities included:

Writing SQL queries to explore the environment conditions of different locations. Finding insights about sensor behavior and change in environmental conditions in a month.

Data Visualization — Power BI- Developed an interactive Power BI dashboard to communicate the results of the analysis.
The dashboard was designed to provide a clear overview of environment conditions and sensor health.
